DSEngine Documentation
======================

DSEngine is a low-code, declarative pipeline engine for automated Data Science exploration, statistical testing, and time series analysis.

Overview
--------
DSEngine allows users to execute complete analytical workflows purely via YAML configuration, requiring zero custom Python code. It automatically generates detailed JSON data payloads and self-contained HTML reports with embedded plots.
